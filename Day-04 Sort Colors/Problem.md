# 🎨 Sort Colors (Dutch National Flag Algorithm)

## 📌 Problem Statement

You are given an array `nums` consisting only of **0s, 1s, and 2s**, where:

- `0` represents **Red**
- `1` represents **White**
- `2` represents **Blue**

Your task is to **sort the array in-place** so that all `0`s come first, followed by `1`s, and then `2`s.

👉 You must solve this **without using extra space**.
