# Next Permutation (In-Place)

## 🧩 Problem Statement

A **permutation** of an array of integers is an arrangement of its elements into a sequence or linear order.

The **next permutation** of an array is defined as the **next lexicographically greater permutation** of its elements.

- If such a permutation exists, rearrange the array into the next greater order.
- If no such permutation exists (i.e., the array is in descending order), rearrange it into the **lowest possible order** (ascending order).

⚠️ The rearrangement must be done **in-place** and use only **constant extra memory**.
